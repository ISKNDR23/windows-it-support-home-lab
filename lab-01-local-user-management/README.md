# Project 01 - Windows Local User Management Lab

## Overview
This lab demonstrates basic Windows user administration using Computer Management.  
The goal was to create a standard local user account, verify its group membership, and confirm successful login.

## Objective
Create and validate a local standard user account for an IT support lab scenario.

## Tools Used
- Windows 10/11
- Computer Management
- Local Users and Groups

## Tasks Performed
1. Opened Computer Management and reviewed existing local users.
2. Created a new standard local account named `support.user`.
3. Added a description for the account.
4. Verified the new account was created successfully.
5. Confirmed the account belongs to the default `Users` group.
6. Logged in using the new account to verify it works properly.
