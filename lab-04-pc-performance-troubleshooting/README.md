# Lab 04 - PC Performance Troubleshooting

## Overview
This lab demonstrates how to investigate and improve Windows system performance using Task Manager and startup optimization.

The system was experiencing high memory usage and 100% disk utilization, which can cause noticeable slowdowns and poor responsiveness.

## Objective
Identify performance bottlenecks and reduce unnecessary resource usage.

## Tools Used
- Windows Task Manager
- Processes
- Performance Monitor
- Startup Apps

## Initial Findings
- Memory usage was approximately 89-91%.
- Disk utilization reached 100%.
- Multiple browsers and background applications were consuming system resources.
- Several unnecessary applications were configured to start automatically with Windows.

## Tasks Performed
1. Reviewed running processes and resource usage in Task Manager.
2. Identified high memory and disk utilization.
3. Reviewed startup applications.
4. Disabled unnecessary startup applications.
5. Closed unnecessary browser processes.
6. Rechecked CPU, memory, and disk usage after optimization.

## Results
After optimization:
- Disk usage decreased significantly from 100% to approximately 6%.
- Memory usage decreased from around 91% to approximately 85%.
- Fewer unnecessary applications were running.
- Startup application load was reduced.
